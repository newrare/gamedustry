# TODO — the newrare game factory

What is left, one line per task. [docs/INDUSTRIALIZATION.md](docs/INDUSTRIALIZATION.md)
holds the reasoning. A task is **removed** once it is verifiably done.

- **MAIN** — a human action: a decision, an account, an upload, a piece of content.
- **AUTO** — a command; no code to write.
- **CODE** — something to develop.

Five scopes are tracked here: **android**, the **content pass on the
games**, **new games** — parked until the thirteen are validated and live on
Google Play — **acquisition** — TikTok and the web portals, un-parked on
2026-09-18 — and **the codebase**. Levels, the meta layer and a village ship
on every game; the ad measurement gate is parked, not done.

## Acquisition — where the players come from

[docs/MARKETING.md](docs/MARKETING.md) holds the reasoning. In short: Play's
algorithm amplifies traction, it does not create it, so the catalogue only pays
off once something feeds them. Two channels do, and neither needs a budget —
short vertical video, and the web portals that bring their own traffic.

### TikTok — the discovery channel

The unit of the lottery is the **clip**, not the game: every art direction
is its own content angle, and a clip costs an hour. This is the one lever
that moves the per-game odds; the portfolio only multiplies them.

- [ ] MAIN — **open the studio account.** TikTok first, then the same captures
  on Shorts and Reels — one capture, three uploads. The bio links the site and
  not a store: the site is the single page that leads to every game
- [ ] CODE — **a pilot per game in `tools/lab/shoot-clip.mjs`.** The capture
  exists (1080×1920 under virtual time, HUD and callouts included, the sound
  logged for the mix) and plays only what a pilot plays: `echomaze` has one,
  the other games do not. A pilot is a hook inside the Game module, like
  `GAME_PILOT` in `shoot-screens.mjs`, playing the round a promo wants to show
- [ ] CODE — **a motion-design promo video for every game**, made with
  HyperFrames. `echomaze` is done: `promo/echomaze/` (composition +
  `promo.json`), rendered by `node tools/lab/promo.mjs echomaze` to
  `dist/promo/echomaze-{en,fr}.mp4`. One per game, FR and EN, the game's own
  shots, art, music and sound as its only inputs
- [ ] MAIN — **review the echomaze promo and post it** — TikTok first, then
  Shorts and Reels
- [ ] MAIN — **write the clip recipe down once**: 15–30 s, vertical, the most
  satisfying beat of the mechanic, no voice-over, cut so it loops. Then ten
  variants of one game before judging any of them — what is being tested is the
  clip, not the game
- [ ] MAIN — **a cadence and a kill criterion.** A clip is dead at 48 h; one
  that passes earns a second round of variants. Attribute the installs it sent:
  `?from=` on a site link, the Play install referrer on a store link

### Search — the site and its guides

The site writes every page in English (`/…`) and French (`/fr/…`), a guide
page per game (`/guide/<slug>`), a `sitemap.xml` and a `robots.txt`
(`tools/build/build-site.mjs`). Google finds the sitemap through `robots.txt`
on its own; declaring it is what makes the indexing visible and faster.

- [ ] MAIN — **declare the site in Google Search Console**, once the build
  with `sitemap.xml` is deployed (`https://newrare.app/sitemap.xml` must
  answer the XML, not a 404):
  1. <https://search.google.com/search-console> → *Add property* → **Domain**
     → `newrare.app`; copy the `google-site-verification=…` TXT record
  1. OVH (the DNS is there: `ns111.ovh.net`) → *Web Cloud → Domain names →
     newrare.app → DNS zone → Add an entry* → **TXT**, sub-domain empty, the
     value pasted; leave the `v=spf1 …` record alone (the mail's)
  1. back in Search Console → *Verify* (minutes to a few hours of propagation)
  1. *Sitemaps* → `sitemap.xml` → *Submit*; expect "Success" and 48 URLs
  1. *URL inspection* → *Request indexing* for `/`, `/fr`, `/guide`,
     `/fr/guide` (the quota is about ten a day)
  1. Bing Webmaster Tools → *Import from Google Search Console* (covers
     DuckDuckGo and Ecosia too)
- [ ] MAIN — **a share image** for the home and the privacy page: 1200×630,
  the studio's look. Their `og:image` is the 192 px logo today (`headBlock` in
  `build-site.mjs`), which a social network shows as a thumbnail rather than
  a card; the guide pages already share their game's desk scene
